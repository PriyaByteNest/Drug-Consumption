💊 Drug Consumption Analysis Using Machine Learning

📌 About the Project

This project analyses drug consumption patterns using Python and Machine Learning techniques. It explores demographic information, personality traits, and consumption categories to understand different patterns of drug usage.

🎯 Objectives

- Analyse drug consumption patterns.
- Perform data cleaning and preprocessing.
- Visualize consumption categories.
- Identify correlations between different substances.
- Predict cannabis consumption categories using Machine Learning.

🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

📂 Dataset

Drug Consumption Dataset ("drug_consumption.data").

The dataset contains demographic details, personality scores, and different substance consumption categories.

🔍 Project Workflow

1. Data Collection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Correlation Analysis
6. Feature Selection (SelectKBest)
7. Model Training and Testing
8. Model Evaluation
9. Best Model Selection

🤖 Machine Learning Algorithms

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

📊 Evaluation Metrics

- Accuracy Score
- Classification Report
- Confusion Matrix
